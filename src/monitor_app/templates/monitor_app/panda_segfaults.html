Segfault Catalog

Payload crashes in ePIC production jobs, one row per crash signature: a job whose payload died on a signal (exit code 128 plus the signal: 139 SIGSEGV, 134 SIGABRT, 135 SIGBUS, 136 SIGFPE), found from the PanDA record and grouped by exit code and PanDA task. The class is read from the record alone: a storm dies at one fixed time across many nodes, a dead configuration crashes every job, a sparse signature crashes a few jobs at varying times and is where event-dependent crashes live. Signatures are promoted as traces and reproductions arrive. Rebuilt nightly by the catalog sync; the crashed jobs behind each row carry their manifest row where the attempt's manifest is on record.
