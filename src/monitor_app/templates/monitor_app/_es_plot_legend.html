Reading the plot. Each lane is one core of the job, running one single-threaded instance of the simulation and reconstruction. A green bar is a unit of consecutive events processed on that core; red is a unit that failed; grey is a core with nothing to do (its start at the head, the drain at the end). The number at the right of a lane is the events that core processed. After a sudden end (a preemption test), light yellow is processing cut off mid-unit and dark yellow is units that finished but whose output never left the node.

Output handling: the blue bars. A finished unit's reconstructed events wait on the node. At each close, on a fixed cadence and once more at the end, the units since the last close are merged into one file, the file is copied off the node to its storage element and checked, and it is registered in Rucio with its event count; only then are those units' events reported to PanDA as done. A blue bar is one close, from the start of the merge to the registration.
